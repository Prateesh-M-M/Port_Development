# Prateesh M M — UX/UI Design Portfolio

A personal portfolio website showcasing my work in UX/UI design, interaction design, user research, prototyping, and emerging technologies.

The portfolio focuses on documenting the design process behind each project, from understanding the problem and conducting research to ideation, prototyping, testing, and final outcomes.

**Designer:** Prateesh M M
**Location:** India
**Field:** UX/UI Design, Interaction Design, HCI

---

## About

I am a UI/UX Design student with an interest in creating useful, accessible, and thoughtful digital experiences.

My approach to design focuses on understanding the problem before designing the solution. I work across user research, information architecture, interaction design, visual design, prototyping, usability testing, and design systems.

I am particularly interested in the intersection of:

* UX/UI Design
* Human-Computer Interaction
* Artificial Intelligence
* Intelligent Interfaces
* Accessibility
* AR/VR
* Emerging Technologies
* 3D and Spatial Experiences

The portfolio is designed to show not only the final interface, but also the reasoning and process behind the design decisions.

## Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm
* Git

You can verify your installations with:

```bash
node --version
npm --version
git --version
```

### Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate into the project:

```bash
cd <project-folder>
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will then be available through the local development URL provided by Vite.

The homepage contains the primary portfolio sections, while each project has its own dedicated case-study page.
