# Prateesh M M — UX/UI Design Portfolio

A personal portfolio website showcasing my work in UX/UI design, interaction design, user research, prototyping, and emerging technologies.

The portfolio focuses on documenting the design process behind each project, from understanding the problem and conducting research to ideation, prototyping, testing, and final outcomes.

**Designer:** Prateesh M M
**Location:** India
**Field:** UX/UI Design, Interaction Design, HCI

---

## About

I am a UI/UX Design student with an interest in creating useful, accessible, and thoughtful digital experiences.

My approach to design focuses on understanding the problem before designing the solution. I work across user research, information architecture, interaction design, visual design, prototyping, usability testing, and design systems.

I am particularly interested in the intersection of:

* UX/UI Design
* Human-Computer Interaction
* Artificial Intelligence
* Intelligent Interfaces
* Accessibility
* AR/VR
* Emerging Technologies
* 3D and Spatial Experiences

The portfolio is designed to show not only the final interface, but also the reasoning and process behind the design decisions.

A language-learning experience focused on making language education more accessible and engaging through thoughtful interaction design.

**Focus:** UX/UI Design, Interaction Design, Education, Prototyping

### Zara Case Study

A UX case study examining the experience of navigating and shopping through a fashion e-commerce platform.

**Focus:** E-commerce UX, User Research, Usability, Interaction Design

## Design Process

The case studies follow a structured design process:

1. **Overview**
2. **Problem Definition**
3. **Research**
4. **User and Stakeholder Analysis**
5. **Design Challenge**
6. **Ideation**
7. **Information Architecture**
8. **Wireframes**
9. **UI Design**
10. **Prototype**
11. **Testing**
12. **Iterations**
13. **Final Solution**
14. **Outcomes and Learnings**

The process is adapted according to the needs of each project rather than treating every project as a fixed checklist.

## Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm
* Git

You can verify your installations with:

```bash
node --version
npm --version
git --version
```

### Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate into the project:

```bash
cd <project-folder>
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will then be available through the local development URL provided by Vite.

## Design Philosophy

The portfolio is built around the idea that good design should communicate both the **solution and the thinking behind it**.

Instead of presenting projects as collections of polished screens, the case studies document:

* What problem was being addressed
* Who experienced the problem
* What research revealed
* What constraints influenced the design
* Why particular design decisions were made
* How the solution was tested
* What changed after testing
* What was learned from the process

This allows each project to demonstrate design reasoning rather than only visual execution.
